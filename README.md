## 📖 Sobre o Projeto

Este repositório contém o código-fonte do site oficial do **Tio Vené (Venelouis)**, hospedado via **GitHub Pages**. 

O projeto foi construído para apresentar a proposta pedagógica, serviços educacionais e frentes de atuação de forma moderna, tecnológica e acolhedora para alunos e responsáveis.

### 🎯 Frentes em Destaque no Site:
- 🏆 **Treinamento para Olimpíadas**: Preparação de alto nível para a **OBI (Olimpíada Brasileira de Informática)** e olimpíadas de raciocínio lógico.
- 💻 **Aulas Particulares Sob Medida**: Acompanhamento 1-on-1 focado no ritmo e no desenvolvimento de projetos reais.
- 🌱 **Clube Amplexo Educação**: Criação de vivências educacionais transformadoras em ciência e tecnologia.

## ✨ Funcionalidades da Aplicação

- **🎨 Design System "Dark Tech"**: Interface moderna com efeito *glassmorphism*, orbes com gradientes fluidos (*ambient glow*) e tipografia moderna (*Plus Jakarta Sans* & *Fira Code*).
- **💻 Terminal Interativo no Hero**: Card estilizado simulando a classe `Aluno` e a metodologia do Tio Vené em Python.
- **🎮 Laboratório Lógico Interativo**: Desafio numérico estilo OBI com validação em tempo real e chuva comemorativa de confetes animados ao acertar.
- **📱 Integração Direta com WhatsApp**: Botões de ação (CTAs) com mensagens pré-formatadas para facilitar o primeiro contato com pais e alunos.
- **❓ FAQ com Acordeão Dinâmico**: Respostas diretas para dúvidas frequentes sobre faixa etária, formato das aulas e requisitos.
- **⚡ 100% Responsivo e Leve**: Otimizado para smartphones, tablets e desktops com Vanilla JS e CSS puro (zero dependências pesadas).
